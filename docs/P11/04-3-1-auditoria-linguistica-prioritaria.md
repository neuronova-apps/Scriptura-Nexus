# P11.4.3.1. Auditoría de herramientas lingüísticas y ampliación prioritaria

Apertura independiente de P11.4.3 a solicitud del responsable. No se declara cierre de publicación del lector: PR #98 y habilitación efectiva/L05 permanecen independientes. Se conserva el avance 61/69 hasta cierres verificables.

## Base y alcance

P8 verificó 3 libros, 1905 unidades y 26750 ocurrencias; 26156 con lema. Se conserva el registro de revisión de LING-010–018: LING-010 (TEHMC) condicional y no incorporada; LING-011/012 WLC y anotaciones OSHB; LING-013 texto SBLGNT; LING-014 anotaciones MorphGNT; LING-015–018 para P11.4.4. Ninguna aprobación de publicación se infiere del lector.

Se auditan seis archivos concretos de cuatro libros: Levítico y Deuteronomio (OSHB, versión fijada), Hechos y 1 Corintios (texto oficial SBLGNT v1.2 y anotaciones MorphGNT de revisión fijada). Los archivos y licencias se fijan a huellas Git, tamaños y SHA-256 cuando ya consta; las huellas SHA-256 pendientes se calculan en CI, no se inventan. Éxodo y Esdras quedan para la ampliación posterior prevista. Se verifican las ocho referencias bloqueadas de SN-001 y SN-008; solo recuentos y elegibilidad técnica, no conclusiones exegéticas.

La auditoría hebrea distingue elementos de palabra brutos y palabras hijas directas de versículo, sin incluir notas o lecturas alternativas en este último recuento. La auditoría griega conserva texto oficial y contrasta forma original exacta por referencia nativa y posición; cuando el número de palabras de un versículo difiere, no propone ninguna anotación para ese versículo. No normaliza para forzar equivalencia ni infiere sentidos, Strong o alineaciones. Las anotaciones CC BY-SA se mantienen separadas de las fuentes de texto CC BY; aprobación y condiciones de redistribución por componente se revisarán después de obtener las huellas.

## Verificación

Cinco pruebas sintéticas, auditoría de las seis fuentes y tres evidencias de licencia mediante HTTPS con límite de bytes y rechazo de redirecciones, y comprobación de compilación pública sin cambios. Solo se imprimen metadatos y recuentos, sin corpus ni archivos de texto persistidos. Las cifras de ampliación no se dan por verificadas hasta el resultado de CI.
