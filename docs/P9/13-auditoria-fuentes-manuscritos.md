No se deduce que una obra antigua autorice cualquier digitalización moderna, fotografía, transcripción, aparato o base de datos. La licencia de un texto y la de sus imágenes, notas, aparato o metadatos deben revisarse por separado.

## 4. Separación respecto de las ediciones admitidas en P9.1

RV1909 permanece clasificada como traducción. SBLGNT v1.2 permanece clasificada como edición textual griega. Ninguna se transforma en testigo manuscrito por estar admitida para proyección técnica. La cobertura OSHB/WLC conserva exactamente el alcance previo y no se amplía en esta subfase. Las referencias a manuscritos dentro de un aparato no autorizan la copia del aparato.

## 5. Registro de derechos y trazabilidad requerido para futuras admisiones

Antes de admitir un testigo o aparato concreto se exigirá: identificador y siglum; institución custodiante y shelfmark; objeto y contenido; URL del catálogo; fuente de imágenes y transcripción; autor/titular y distribuidor; edición/versión y fecha; licencia por componente; evidencia oficial; permisos escritos cuando correspondan; atribución; modificaciones; territorios; checksum SHA-256 de cada archivo admitido; formato; responsable y fecha de aprobación. Si algún dato no se puede verificar, permanece pendiente y no se publica.

## 6. Criterio de salida

P9.4.1 queda preparada para revisión automatizada del inventario. No se declara admitida ninguna fuente. P9.4.2 deberá definir contratos separados para testigo, edición, locus, lectura, aparato, traducción, imagen y procedencia, sin habilitar todavía contenido no autorizado.
